方法論與黑客松評審對齊說明

STEP 1｜損益兩平點（BEP）決策樹

守備方目標是讓「傳三壘期望失分」低於「穩傳一／二壘期望失分」（後段局數則最大化守備方勝率 WE）：

BEP = (RE_滿壘失敗 − RE_穩傳) / (RE_滿壘失敗 − RE_封殺三壘成功)

以 CPBL 0 出局一二壘為例：(2.34 − 1.41) / (2.34 − 0.915) = 65.3%；但到 9 局下平手時，穩傳讓跑者上三壘幾乎必敗，BEP 會驟降至 ~40%，守備方應果斷拚三壘。

STEP 2｜時間差邏輯斯模型（Time-Margin）

為了讓中職與業餘教練僅憑碼錶就能操作，模型將封殺機率拆解為球與跑者的賽跑：

Time Margin = T_跑者(二壘→三壘) − (T_滾動 + T_轉傳 + T_傳球飛行 + 0.08s)

透過邏輯斯轉換 P = 1 / (1 + exp(-Margin / 0.18)) 計算內野每一個 (x, y) 座標點的封殺成功率，並疊加 2026 MLB 實戰 2,375 筆事件進行對照驗證。
